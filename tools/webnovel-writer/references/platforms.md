# 平台数据库

## 国内平台

### 番茄小说 (fanqienovel.com)

| 维度 | 要求 |
|------|------|
| **签约门槛** | 2 万字可申请签约，编辑审核内容质量 |
| **核心读者** | 18-35 岁，偏好快节奏、强情绪 |
| **热门类型** | 都市、玄幻、言情、悬疑、系统流 |
| **书名风格** | 直白信息型：「封总，门口三个奶娃告你抛妻弃子」「重生之都市修仙」 |
| **黄金三章** | 极度重要。前三章决定编辑是否签约 |
| **爽点密度** | 要求高，每 500-800 字需要一个情绪刺激 |
| **章节长度** | 2000-4000 字/章 |
| **更新频率** | 日更 4000+ 字为佳 |
| **独家要求** | 签约后通常要求独家 |
| **收入模式** | 广告分成 + 读者打赏 |
| **避坑** | 开篇不可平淡、不可大段世界观、不可无冲突日常 |

### 起点中文网 (qidian.com)

| 维度 | 要求 |
|------|------|
| **签约门槛** | 3-5 万字可申请，编辑审核 + 数据表现 |

| **热门类型** | 玄幻、仙侠、都市、历史、科幻 |
| **书名风格** | 偏含蓄但需辨识度：「诡秘之主」「大奉打更人」 |
| **黄金三章** | 重要但不极端，可稍慢热 |
| **爽点密度** | 中等，允许铺垫，但要有长期期待感 |
| **章节长度** | 3000-5000 字/章 |
| **更新频率** | 日更 4000-6000 字 |
| **独家要求** | 签约后独家 |
| **收入模式** | 订阅 + 打赏 |
| **避坑** | 不可节奏过慢无进展、不可逻辑漏洞明显 |

## 海外平台

### Webnovel (webnovel.com)

| 维度 | 要求 |
|------|------|
| **签约门槛** | 英文 2-3 万字可申请签约 |
| **核心读者** | 全球，偏好系统流、穿越、玄幻、游戏异界 |
| **热门类型** | LitRPG、Cultivation（修仙）、System、Isekai（异世界） |
| **书名风格** | 信息直给：「Supreme Magus」「Shadow Slave」「My Vampire System」 |
| **爽点** | 侧重力量升级（power progression）和系统奖励 |
| **章节长度** | 1500-2500 words |
| **更新频率** | 日更 1-2 章 |
| **独家要求** | 签约后独家 |
| **语言** | 英文（可翻译，但最好直接写英文或专业翻译） |
| **避坑** | 不可文化梗过重、不可节奏慢、开头必须有系统或金手指 |

### Amazon Kindle Direct Publishing (kdp.amazon.com)

| 维度 | 要求 |
|------|------|
| **门槛** | 无审核门槛，直接发布 |
| **核心读者** | 全球英文读者 |
| **热门类型** | LitRPG、Fantasy、Romance、Sci-Fi |
| **收入模式** | 版税 35%-70% + Kindle Unlimited 分成 |
| **特点** | 自己营销、封面设计极重要、系列化（series）是王道 |
| **避坑** | 不可封面差、不可无系列规划、不可忽视关键词/分类优化 |

### Royal Road (royalroad.com)

| 维度 | 要求 |
|------|------|
| **门槛** | 无签约门槛，免费发布 |
| **核心读者** | 硬核 LitRPG/奇幻/科幻读者 |

| **用途** | 建立读者基础 → 引流到 Patreon/Kindle |
| **避坑** | 不可忽视读者互动、不可节奏慢（这里读者极挑剔） |

## 投稿策略

### 策略 A：单平台深度（推荐新人）

先专注一个平台写到签约。番茄或七猫门槛低，适合起步。

### 策略 B：多平台分发

同一本书在**非独家平台**同步发布。注意：
- 番茄、起点、七猫签约后通常要求独家 —— 不可同时投
- Royal Road + Patreon + Kindle 是海外常用组合
- 未签约期间可多平台分发测试市场反应

### 策略 C：一书多版

同一核心故事，根据平台特性调整：
- 番茄版：快节奏 + 爽点加密
- 起点版：加深世界观 + 扩展支线
- Webnovel 版：强化系统元素 + 英文优化
