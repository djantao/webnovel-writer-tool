# 场景写作指导

AI 写正文时的场景级模板。解决"AI 知道不要什么，但不知道要什么"的问题。

---

## 五种场景类型

### 类型 1：动作/战斗戏

**目的：** 制造紧张，展示能力，推进冲突。

**节奏规则：**
- 短句为主（5-15 字），制造急促感
- 核心动作每 2-3 句插入一次感官（声音、痛感、气味）
- 每 300 字有一次"局势变化"（优势易手、意外发生、环境被利用）

**句式节奏示范：**
```
剑气到了。 ← 3 字，突然
他侧身，剑锋擦过耳廓，削下一缕头发。 ← 动作 + 感官 + 后果
对方没有给他喘息的机会，第二剑紧随其后。 ← 升级
他退了。 ← 2 字，反常规——主角在退
不是因为怕，而是因为他在等。 ← 揭示真正意图
```

**AI 常见错误：**
- 战斗写成"他打了 X，X 挡住了，X 又打了他"的回合制
- 没有环境参与（战斗场景的物件、地形应该被利用）
- 缺少代价（打完应该疼、累、伤——不受伤的战斗无紧张感）

**模板骨架：**
```
[触发：谁/什么发动了攻击或行动]
[动作 + 感官描写（声音/触觉）]
[局势变化：意外/反击/环境因素]
[代价显现：受伤/消耗/牺牲某物]
[结果：赢了/逃了/拖住了——但暴露了新问题]
```

### 类型 2：对话/交锋戏

**目的：** 通过对话推进情节、暴露信息、塑造角色。

**节奏规则：**
- 对白 + 动作/表情/停顿交替，永远不要让两个人在真空中对话
- 每 3-4 轮对话后，场景必须发生一个微小变化（位置、情绪、权力关系）
- 最有力的话往往是最短的

**潜台词结构示范：**
```
"你查过那封信了。" ← 表面：陈述事实。真实：我知道你查了，你在瞒着我什么。
"查了。" ← 表面：确认。真实：但我不会主动告诉你我发现了什么。
她等着。 ← 动作代替对话，制造张力
"...没什么特别的。" ← 表面：否定。真实：他在试探她知不知道更多。
```

**AI 常见错误：**
- "乒乓球对话"——只交换信息，没有张力和潜台词
- 对话中间没有动作——两个人面对面光说话
- 所有角色说话方式一样

**模板骨架：**
```
[对话前的场景锚点：谁在什么地方，在做什么——一句话]
[第一轮：A 说表面话，B 非语言反应（动作/表情）]
[第二轮：B 的回应有潜台词，A 察觉到或没察觉到]
[微变化：一个人站起来/转头/放下杯子/靠近一步]
[第三轮：信息揭示或关系变化]
[收尾：对话结束后的沉默/动作——让刚才的对话在读者脑子里回响]
```

### 类型 3：心理/情绪戏

**目的：** 让读者感受主角的内心世界，建立共情。

**节奏规则：**
- 事件 → 身体反应（下意识）→ 情绪命名 → 联想/回忆 → 决定
- 不要只写"他很愤怒"——写愤怒如何在身体里发酵
- 好的内心戏一定包含"矛盾"——两种互相冲突的情绪或想法

**情绪链条示范：**
```
系统提示消失了。

他的第一反应不是狂喜。是空。 ← 身体/情绪反应
就好像一直在追的东西突然到了手，不知道接下来该追什么。 ← 联想
他在床边坐了很长时间。窗外从黑变成灰。 ← 时间流逝，环境衬内心
然后他站起来。不是因为想通了。是因为天亮了，该干活了。 ← 矛盾：不是释然，是硬撑
```

**AI 常见错误：**
- 跳过情绪直接进入行动（事件 → 下一步，中间没有情绪段落）
- 用抽象词替代感受（"他很悲伤"——悲伤的表达是具体的、身体的）
- 情绪过于单一（同一时刻可以有互相矛盾的情绪）

**模板骨架：**
```
[触发事件]
[身体反应（本能，不可控的）：心跳、呼吸、手抖、喉咙发紧]
[情绪命名 + 联想（这件事让主角想起什么）]
[矛盾情绪（另一个感受同时出现）]
[决定或行动（被其中一种情绪推动）]
```

### 类型 4：过渡/衔接戏

**目的：** 连接两个重要场景，保持节奏但不过度消耗读者注意力。

**节奏规则：**
- 过渡戏不超过 300 字
- 必须包含一个信息增量（哪怕很小）——纯过渡等于水字数
- 结尾埋一个微小钩子

**正确示范：**
```
从练功房到前厅，三百步。 ← 空间转换
陆尘走得很慢。不是因为伤势——伤势早就好了。是因为他在算。 ← 信息增量
九长老的话里有一个词不对。不是"灵脉崩解"，是"灵脉剥离"。 ← 推进情节
崩解和剥离，一个是天灾，一个是人祸。 ← 推理
他停在前厅门口。里面有人在等他。他听得到呼吸声。三个。 ← 微小钩子
```

**AI 常见错误：**
- 纯环境/路程描写作为过渡（"他走过长廊，长廊很美，他继续走"）
- 用"三天后"频繁替代过渡

**模板骨架：**
```
[空间/时间转换：一句话]
[一个微小的事件/观察/想法——不能是空的]
[这个事件/观察/想法带来的变化]
[下一个场景的入口钩子]
```

---

### 类型 5：爽点释放戏

**目的：** 让读者获得情绪满足——读者花钱看书的理由。

**节奏规则：**
- 三步：引爆 → 回响 → 推向下一阶段
- 引爆的句子必须短而有画面感
- 必须写旁观者反应——旁观者的震惊是爽感的放大器
- 爽完之后不能停——必须暗示"下一个更大的目标"

**A 级爽点（打脸）模板骨架：**
```
[引爆：事实暴露的那一刻，用最短的句子]
[被打脸者的反应（不可置信 → 沉默 → 愤怒/恐惧）——逐一写]
[旁观者的反应（震惊、议论、态度转变）——用具体人物的具体反应]
[主角的反应（不是得意——是平静/冷漠/不在意，这比得意更爽）]
[回响：刚才那一幕的意义——不只是赢了，是推翻了某种"本该如此"]
[推向下一阶段：但更大的对手/问题出现了]
```

**AI 常见错误：**
- 打脸之后主角长篇大论解释——真正强的人不需要解释
- 没有旁观者反应——打脸在真空中进行
- 爽完之后原地踏步——没有"下一个目标"的暗示

## 场景衔接规则

| 前场景 | 后场景 | 衔接方式 |
|--------|--------|---------|
| 动作戏 | 对话戏 | 用"代价/伤势"过渡——打完之后的喘息/疗伤/善后 |
| 对话戏 | 心理戏 | 对话中的某个词/表情触发主角的内心波澜 |
| 心理戏 | 动作戏 | 内心决定 → 立即行动（不拖沓） |
| 爽点戏 | 任意 | 回响中暗藏"下一个更大的问题" |
| 过渡戏 | 任意 | 以"微小钩子"收尾 |

## 每章场景配比建议（2000-4000 字章）

| 场景类型 | 占比 | 说明 |
|---------|------|------|
| 动作/战斗 | 0-40% | 高潮章用到 40%，铺垫章可能为 0 |
| 对话/交锋 | 20-40% | 每章必须有——网文是对话驱动的 |
| 心理/情绪 | 10-20% | 关键事件后必须有，不可省略 |
| 过渡/衔接 | 5-10% | 精简，每段不超过 300 字 |
| 爽点释放 | 10-20% | 每章至少一次，哪怕只是 C 级 |
