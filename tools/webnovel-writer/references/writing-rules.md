# 写作规则库

## 反 AI 味规则

### R1：句式变异

连续 3 句话不能出现相同句式结构。

**什么是相同句式：**
- "他 + 动词 + 了 + 宾语" 连续使用
- "在 + 地点 + 主语 + 动词" 连续使用
- 三个句子都以"这""那""他"开头

**正确：**
```
门外的脚步声越来越近。他屏住呼吸。冷汗顺着脊背滑下来。
```
三句长度 9/5/8 字，主语不同，节奏在变。

**AI 典型错误：**
```
他走到了门口。他打开了门。他看到外面站着一个人。
```
句式完全相同，必须改写。

### R2：感官落地

每 500 字至少出现 2 处具体感官描写（视觉之外）。

**感官清单：** 听觉、嗅觉、触觉、味觉

**示例：**
- 听觉：「楼道里传来高跟鞋的声音，由远及近，每一步都像踩在他太阳穴上。」
- 嗅觉：「房间里有一股铁锈的味道，甜腻的，像刚凝固的血。」
- 触觉：「她的手指冰凉，指腹有薄茧，不像一个养尊处优的大小姐。」

**AI 典型错误：** 全章只有视觉描写（"他看到""他看见""出现在眼前"）。

### R3：对话有层

每段对话必须有"表面意思"和"真实意图"两层。

**正确：**
```
"你回来了。"她说。（表面：陈述。真实意图：你为什么这么晚才回来？）
"嗯。"他没看她。（表面：确认。真实意图：我不打算解释。）
```

**AI 典型错误：**
```
"你好。""你好。""今天天气不错。""是的，天气不错。"
```
信息量 = 字面量，读者一眼扫过毫无感觉。

### R4：情绪反应

每发生一个重大事件，必须用至少 2 句从主角视角写情绪反应。

**重大事件包括：** 获得/失去重要物品、遭遇/逃脱危险、得知关键信息、被人羞辱/赞扬

**正确：**
```
系统提示：力量 +10。

李默盯着那行字，心脏猛地跳了一下。十天，他等了整整十天，终于等到了第一次属性增长。不是因为加十点力量有多强，而是因为这说明——他的猜测是对的。
```

**AI 典型错误：** 事件发生后直接进入下一步行动，无情绪停顿。

### R5：禁用过渡词

"然而""与此同时""不仅如此""总之""由此可见"——每章每种不超过 2 次。

**AI 典型错误：**
```
他被打倒在地。然而他并没有放弃。与此同时门外响起了警笛声。不仅如此他还听到了熟悉的声音。
```
改写：直接用动作和感官连接，不需要过渡词。

### R6：示而不述

用动作和对话展示，不用抽象叙述直接告诉读者结论。

**正确（示）：**
```
张总把合同推回来，没看。他端起茶杯，吹了吹，水面上浮着一片没泡开的茶叶。"小李啊，你来了公司三年了吧。"他说，语气像在聊天气。
```

**AI 典型错误（述）：**
```
张总很生气，而且对合同非常不满意。他对小李的工作能力产生了严重的怀疑。
```

### R7：角色语音锁定

**这是对话质量的核心规则。** 每个角色必须有可辨识的说话方式，禁止全角色共用同一种"中性短句风"。

#### 角色语音三要素

每个角色在档案中必须定义：

| 要素 | 说明 | 示例 |
|:----:|------|------|
| 语速 | 快/中/慢 + 句式特征 | 快→连说少停顿；慢→长句有顿挫 |
| 句式 | 断言式/试探式/反问式/命令式 | 陈胖：试探式，说半句停半句 |
| 口头禅+禁用语 | 3-5个标志词/短语 + 绝对不会说的话 | 张扬：标志"科学来说"；禁"可能""也许" |

#### 硬约束

**1. 每章角色对话必须通过"遮名测试"：**

遮住角色名，读对话正文——能认出是谁在说话吗？不能→失败。识别要点：
- 主角：话少，短句直给，不解释。一个字能说完不用两个字。
- 配角：必须和主角形成节奏差异。至少有一个配角的对话长度是主角的2-3倍。

**2. "不是X，是Y"句式禁止出现在角色对话中：**

这个句式属于旁白/叙事，不属于口语。角色说"不是A，是B"的替换方式：

```
❌ 陈胖："不是激动。是认了。"
✅ 陈胖："我...我不是激动。我就是——认了。"
   （加口语杂质：重复、停顿、填充词"就是"）

❌ 程渡："不是客气。是觉得有意思。"
✅ 程渡："啧，不是客气——真觉得有意思。"
   （用语气词"啧"破开，连成一句不拆碎）
```

**3. 角色对话禁止出现主角专属的叙事风格：**

以下特征属于主角叙事声音，禁止出现在其他角色对话中：
- 二字短句堆积（"评。评理。评剑。评人。"）
- 抽象哲理解构（"不是X，是Y"、"传。比教重。"）
- 单字独立成段（"嗯。"作为独立段落仅限于主角）

**4. 角色语音速查表（生成对话时逐条对照）：**

| 角色 | 语速 | 句式 | 标志词 | 禁用语 |
|------|:----:|------|------|------|
| 江临渊 | 慢 | 短句直给，不解释 | "行。""不错。""嗯。" | "我好难""帮帮我""可能是" |
| 陈胖 | 慢 | 试探式，说半句停半句 | "对不起""谢谢""江教练..." | "不是X是Y"解构句式 |
| 程渡 | 快 | 反问+调侃，连说少停顿 | "啧。""行吧。""妈的" | 长串停顿（"以前——和我妈——"） |
| 老周 | 中 | 唠叨式，长句有温度 | "你听我的。""我跟你说。" | 短句直给 |
| 张扬 | 中 | 断言式，不犹豫 | "科学来说""你不懂" | "可能""也许""大概" |
| 刘雨桐 | 快 | 命令式，对自己狠 | "我可以。""再来。" | "我不行""算了吧" |
| 小杨 | 快 | 嘴快，天然友好 | "哇靠""真的假的" | — |
| 顾长风 | 慢 | 长句，自问自答 | "你还不明白吗。" | 短句直给 |
| 赵一帆 | 慢 | 试探式，比陈胖更碎 | "那个...""对不起" | 完整长句 |
| 苏姐 | 中 | 陈述式，温但坚定 | "我想试试。""这辈子。" | "算了吧" |

**硬约束：** 生成对话时，先查此表，再写对话。每个角色对话必须匹配其"语速+句式+标志词"。检查方法：写完一章后，单独提取角色A的全部对话，连续读——如果读起来像主角在说话，重写。

## 钩子模式库

### 模式 1：身份错位

角色出现在不该出现的位置，或拥有不该拥有的身份。

**示例：** 退婚的废柴出现在天才选拔赛决赛现场；总裁的"司机"实际是集团真正控股人

**适配：** 爽点 A-S 级打脸型

### 模式 2：信息不对等

读者知道的信息比某些角色多，产生紧张或期待。

**示例：** 读者知道主角是卧底但反派不知道；读者知道杯子里有毒但主角端起来准备喝

**适配：** 危险之钩、信息之钩

### 模式 3：坠落预期

从高位坠落，制造"不公平感"。

**示例：** 天才一夜修为尽失；大小姐被家族驱逐身无分文；兵王退役被当废人安排做保安

**适配：** 不公之钩（效果最强）

### 模式 4：倒计时

主角必须在限定时间内完成某件事。

**示例：** 三小时内筹不到钱妹妹的手术就取消；天亮前没找到线索凶手就离开

**适配：** 危险之钩

### 模式 5：反常事件

打破日常规律的一个异常事件，暗示更大的秘密。

**示例：** 从教第十年的老师收到一封十年前写给自己的信；从来不开的对门突然开了

**适配：** 信息之钩

## 爽点公式

### 公式 1：压 + 爆

1. **压**（制造落差）：让主角被低估、被轻视、被欺辱
2. **蓄**（积累势能）：主角默默准备、暗中成长
3. **爆**（释放）：在所有人都不看好的时候一击逆转

压得越狠，爆得越爽。压不够，爆就是挠痒。

### 公式 2：揭 + 震

1. **掩**（隐藏真相）：主角真实身份/实力被隐藏
2. **露**（事件触发）：一个事件迫使真相暴露
3. **震**（他人反应）：用旁观者的震惊放大爽感

越是之前看不起主角的人，震惊越爽。

### 公式 3：得 + 证

1. **缺**（渴望缺失）：主角极度渴望某样东西
2. **争**（付出代价）：主角为之付出巨大代价
3. **得**（获得回报）：在即将失去的边缘获得回报

读者需要先感受到"如果得不到会有多痛"。

## 节奏控制

### 每章情绪曲线

开头（10%）：钩子落地，制造张力
中段（70%）：冲突升级，张力逐步攀升
爽点（80-90% 位置）：情绪释放
结尾（最后 10%）：新问题出现，推往下一章

### 章节间节奏衔接

- **连续高强度错误：** 章章都是 S 级爽点 → 读者麻木
- **连续低强度错误：** 连续 3 章无 B 级以上爽点 → 读者弃书
- **正确节律：** C → B → A → S → C → B → A → S（螺旋上升，有高峰有缓冲）

## 常见类型套路

### 都市爽文

1. 开篇必须落魄（离婚/失业/重病）或隐藏身份（大佬装废物）
2. 第一次打脸必须在第 3 章之前
3. 前 10 章必须完成：身份揭示 → 第一次碾压 → 建立势力

### 玄幻修真

1. 开篇必须是"坠落瞬间"——一下子从高处摔下来
2. 金手指（特殊能力/系统）必须在第 2 章之前激活
3. 第 3-5 章必须完成第一次突破

### 言情甜宠

1. 第一次男女主相遇必须在第 1 章内
2. 相遇方式必须有冲突或误会（不可平淡相识）
3. 第 3 章前必须有"男主护女主"或"女主对男主改观"的瞬间

### 武侠/玄幻

#### 规则1：禁止高密度短分段

AI 生成文本极爱一句一段、半句换行。真人手写武侠会适度合并短句，不会把所有短句强行拆成独立段落。

**AI 典型错误：**
```
剑尖停在他喉前三寸。

再往前半寸，喉骨就碎了。

他的手在抖。

剑稳，手不稳。

我把剑收回来。
```

**正确（合并短句，保留节奏）：**
```
剑尖停在他喉前三寸。再往前半寸，喉骨就碎了。

他的手在抖。剑稳，手不稳。面前这个年轻人二十出头，用的剑比他的肩膀还宽。

我把剑收回来。
```

**硬约束：** 同一场景内，连续3个以上单句独立成段，必须合并至少2句为一个自然段。

#### 规则2：避免连续短句排比

AI 偏好在同一段落内连续使用多组同类拆分排比（"评理。评剑。评人。" → "不用惊堂木。用剑。"），句式节奏均匀规整，缺少人写的错落语感。

**AI 典型错误：**
```
我做的最多的事是评。评理。评剑。评人。有时候觉得自己像个县太爷——不用惊堂木。用剑。
```

**正确（打破排比均匀节奏，用破折号或逗号合并，或插入长句打断）：**
```
我做的最多的事是评——评理、评剑、评人。有时候觉得自己像个县太爷。不用惊堂木。用剑。
```

**硬约束：** 同一段落内，连续2组以上相同结构的短句排比（如"X。X。X。"后紧跟"Y。Y。"），必须打破至少一组。

#### 规则3：章节结尾伏笔必须有过渡

AI 很喜欢在章节末尾丢一个孤立悬疑伏笔，不做任何铺垫过渡，戛然而止。真人手写会铺垫一句环境、一点心理活动或动作再收束，不会突兀单放一个线索收尾。

**AI 典型错误：**
```
山脚下。白天太监站过的地方。有一只鞋印——太小，太细。女人的鞋底。

没有人注意到。
```

**正确（加过渡动作或心理）：**
```
走到半路我停了一下。山脚下，白天太监站过的地方，碎石上有一道痕迹。太细，不像男人的。女人的鞋印。风一吹，松针落下来，盖住了大半。

没人注意到。
```

**硬约束：** 章节结尾的伏笔揭示前，必须有至少1句主角动作/心理/环境过渡，禁止直接抛出孤立线索。

#### 规则4：禁止工整对仗式对话

AI 偏爱让角色对话形成逻辑完美闭环的工整对仗，每句都像在写对联。真人对话会带一点卡顿、口语杂质、不完美的接话。

**AI 典型错误：**
```
画师说这是画像。打架有打架的眼神，画像有画像的。不一样。
```

**正确（打破工整，加入口语杂质）：**
```
画师说这是画像——供在殿里的，自然要端庄。我说师父从来就没端庄过。画师愣了一下，没接话。
```

**硬约束：** 角色对话中禁止出现"A有A的X，B有B的Y"或"X有X的XX，Y有Y的YY"类对仗结构。替代表达：让角色说半句、卡住、换话题、或对方没接住。

#### 规则5：武侠动作描写必须有"声音"

武侠打斗不应只有视觉（"剑光一闪""掌风呼啸"），必须有具体的声音——兵器碰撞声、脚步摩擦声、呼吸声、布料撕裂声。

**正确：**
```
练武场上只有风吹松针的声音。
他的剑尖擦过石阶——刺耳的"吱"一声。
师弟的拳头打到树上，闷响。不是骨头碰木头——是气。内功。
```

**硬约束：** 每场打斗场景至少出现2种不同的声音描写。

#### 规则6：特殊句式/分段 每章频次上限

"不是X，是Y"句式和碎片化短分段（连续3个以上单句独立成段），都是AI高频输出特征。但真人手写也会偶尔使用——作为修辞强调或节奏控制。关键在于**频次**：AI会滥用，真人会克制。

**硬约束：**

| 特征 | 每章上限 | 说明 |
|------|:--------:|------|
| "不是X，是Y"句式 | 1-2次 | 超出视为AI味滥用。替代表达见规则4 |
| 碎片化短分段（连续3+单句独立成段） | 1-2处 | 超出视为AI味滥用。合并方案见规则1、规则7 |

**检测方法：**
- 用Grep搜索`不是.*[，。].*是`统计"不是X，是Y"出现次数
- 逐段检查连续3个以上单句独立成段的位置

**超出上限时：** 前2次保留（作为修辞），其余全部按规则1/规则4替换。

#### 规则7：自然合并——合并短分段不能只改标点

AI最大的偷懒方式：把连续3+单句独立成段合并时，只把句号改成逗号，变成"流水句"。真人手写会加口语连接词、调整语序、加入停顿，让句子真正像人说话。

**AI典型错误（只改标点）：**
```
❌ 我擦器械。擦了两遍。第三遍——
❌ 我擦器械，擦了两遍，第三遍——
```
只是把句号换成逗号，读起来仍然生硬。

**正确（加口语连接词+调整语序）：**
```
✅ 我擦器械，擦了两遍，到第三遍的时候——
```

**AI典型错误：**
```
❌ 他停下来。是个胖胖的年轻人。个子不高。T恤上印着卡通猫。气喘不上来，脸很红。
❌ 他停下来，是个胖胖的年轻人，个子不高，T恤上印着卡通猫，气喘不上来，脸很红。
```

**正确：**
```
✅ 他停下来，是个胖胖的年轻人，个子不高，T恤上还印着卡通猫呢，气喘不上来，脸涨得通红。
```
加了"还""呢""涨得"，句子有了口语感。

**AI典型错误：**
```
❌ 腰没塌。但他自己没感觉到差别——只觉得这组比以前轻松。
❌ 腰没塌，但他自己没感觉到差别——只觉得这组比以前轻松。
```

**正确：**
```
✅ 腰倒是没塌，不过他自己没感觉到差别——只觉得这组比以前轻松些。
```
加了"倒是""不过""些"，语气更自然。

**AI典型错误：**
```
❌ 第二天。他又来了。腿举机旁边那个位置。看见我在擦器械。犹豫了一下。走过来。
❌ 第二天，他又来了，腿举机旁边那个位置，看见我在擦器械，犹豫了一下，走过来。
```

**正确：**
```
✅ 第二天，他又来了，还是腿举机旁边那个位置，看见我在擦器械，犹豫了好一会儿才走过来。
```
加了"还是""好一会儿""才"，有了时间感和心理活动。

**常用口语连接词清单（合并时优先选用）：**

| 功能 | 连接词 | 示例 |
