# 章节规划模板

在阶段 2（搭骨架）阶段，AI 需要按此模板为每章生成规划。

---

## 第 N 章规划

### 基础信息

- **章号：** N
- **本章功能：** （铺垫章 / 爽点章 / 过渡章 / 逆转章）
- **衔接上一章：** 因上一章的 [事件] → 所以本章 [事件]

### 钩子（前 500 字）

- **钩子类型：** 不公之钩 / 信息之钩 / 危险之钩
- **具体内容：** 一句话描述本章开头用什么情境抓住读者
- **钩子强度（自评 1-5）：** ___

### 本章冲突

- **核心冲突：** （一个句子——主角想要 X，但 Y 阻碍）
- **冲突升级方式：** （阻碍如何变得越来越严重）

### 爽点

- **爽点等级：** C / B / A / S
- **爽点位置：** 本章约 ____ 字处
- **爽点内容：** 一句话描述读者会为什么感到爽

### 章尾推法

- **推法类型：** 断章式 / 升级式 / 反转式
- **具体内容：** 一句话描述本章结尾用什么方式让读者必须翻下一页

### 因果链

- **因（从上一章来）：** ____
- **果（推向下一章）：** ____

---

## 示例：第 1 章规划（玄幻题材）

### 基础信息

- **章号：** 1
- **本章功能：** 铺垫章
- **衔接上一章：** 全书开篇

### 钩子（前 500 字）

- **钩子类型：** 不公之钩
- **具体内容：** 主角陆尘在宗门大比中被当众宣布"修为尽失、逐出宗门"，台下曾经仰望他的人发出嘲笑。师父没有看他一眼。
- **钩子强度（自评 1-5）：** 4

### 本章冲突

- **核心冲突：** 陆尘想保留最后的尊严离开宗门，但曾经输给他的人要当众羞辱他
- **冲突升级方式：** 从语言羞辱 → 搜身夺走仅剩的丹药 → 把他从山门台阶上推下去

### 爽点

- **爽点等级：** C
- **爽点位置：** 本章约 2500 字处
- **爽点内容：** 陆尘被推下台阶时，用他自创的凡人手法暗中伤了对方——对方不知道怎么回事但疼得跪下了。读者知道陆尘没有真的变废，但宗门不知道。

### 章尾推法

- **推法类型：** 反转式
- **具体内容：** 陆尘跌落在山脚时，手腕上从未反应过的黑色旧镯子突然发烫，一行字浮现在他脑海中："检测到宿主灵脉被毁，是否开启替代修炼路线？"

### 因果链

- **因（从上一章来）：** 开篇
- **果（推向下一章）：** 镯子激活 → 第 2 章探索新能力
