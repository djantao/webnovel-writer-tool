# 第12章 记忆快照

1. 站桩第三天——刘雨桐腿不抖了，站了三十分钟，膝盖不疼了。江临渊说"站桩练的是气"

3. 陈胖老婆第一次出现——站姿和刘雨桐刚来时一样，"重心在脚尖，怕胖"，开始站桩训练
