# 第17章 记忆快照

## 本章要点（3句）
1. 张扬朋友圈引发风波——截图发到本地健身教练群，两百多人讨论。老周接退卡电话，烟灰缸十个烟头。
2. 刘雨桐维护主角——当面删张扬好友，说"谁有证谁没证不重要，重要的是谁把我的膝盖教好了"。张扬删了朋友圈。
3. 陈胖带同事老王来——久坐腰肌劳损，练站桩一分钟撑不住。实操考试报名表到手，下周个体校，罗教练。

## 角色状态变化
- 江临渊：面临证书危机——张扬暗箭，但学员用行动支持。实操考试在即
- 刘雨桐：从学员→维护者——当面删张扬好友，公开维护主角。站桩十五分钟腿不抖
- 张扬：从暗讽→删帖——刘雨桐的话让他无法反驳，删了朋友圈
- 老周：从担忧→支持——接退卡电话后决定保护主角，"张扬的事——我来处理"

## 新揭示设定
- 老周的底线——十年健身房，规矩比他清楚，但他站在主角这边
- 刘雨桐的转变——从怕看膝盖→不怕露疤痕，"忘了遮"→"不怕了"
- 罗教练主动打电话——"按规矩评，不管他是不是你的人"

## 新埋线索
- 实操考试下周——罗教练是张扬师兄，"科学健身，数据说话"
- 老王加入训练——陈胖推荐的同事，久坐腰肌劳损
- 老周承诺剑南春——"考过了——剑南春。我请。"
