# 第19章 记忆快照

## 本章要点（3句）
1. 高姐出场——四十多岁，膝盖不能弯，走路一瘸一拐，经人介绍来试试，抱怀疑态度
2. 三学员站桩对比——陈胖（稳但胖，用"扛水泥"点拨）、高姐（比老王标准，膝盖问题，用"脚下有根"点拨）、老王（抖得厉害但坚持，用"坐在椅子上"点拨）
3. 笔记本接近突破——记录呼吸、意念、气三者合一，结尾写下"气走丹田，落于足跟，贯于百会。不是力气——是气脉。"

## 角色状态变化
- 高姐：怀疑→半信半疑→站桩后膝盖有热感
- 老王：站桩从一分钟到五分钟，呼吸稳了
- 陈胖：站桩越来越稳，开始理解"用意不用力"
- 江临渊：笔记本"气脉"概念接近突破，能针对不同学员用不同点拨方式

## 新揭示设定
- 站桩三要素雏形：呼吸（腹式呼吸）、意念（意守丹田）、气（气脉运行）
- 不同的人需要不同的点拨方式——因材施教
- 高姐膝盖的气感验证了气脉健身法对慢性病的效果
