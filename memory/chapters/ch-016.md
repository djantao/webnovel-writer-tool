# 第16章 记忆快照

## 本章要点（3句）
1. 火锅局——顾长风再次邀请合伙，主角拒绝。顾长风透露陆沉在成都开茶馆
2. 陆沉的真相——三百年前天牢背叛，现在在宽窄巷子开茶馆，认出主角视频但没来找
3. 顾长风的联盟提议——帮主角补过去、背书气脉健身法，条件是别去陆沉的茶馆

## 角色状态变化
- 江临渊：拒绝顾长风合伙→知道陆沉在成都→程渡发现主角被关过的秘密
- 顾长风：从挑战者→联盟者。"江水东流，不改其性。你做到了，我没做到。"
- 程渡：发现主角秘密——"你以前是不是被关过"，主角承认
- 陆沉：新角色正式登场（虽未露面）——三百年前背叛者，现在独自开茶馆

## 新揭示设定
- 陆沉穿越比顾长风早半年，在茶馆打工，老板死后接手，老板子女闹过三天后不闹了
- 实操考试考官罗教练是张扬的师兄——张扬朋友圈是给罗教练看的
- 顾长风的生存哲学——"按规矩混，才能活得好"
- 陆沉泡铁观音——三百年前的旧习惯，杯沿缺了一小块的青花瓷杯
- 顾长风的评价——"他欠你的不止是一条命，他欠你的是一个门派"

## 新埋线索
- 实操考试下周——罗教练"按规矩来"，主角方法不被认可

- 条件：别去陆沉的茶馆——"你去了，他撑不住"
- 陆沉哭了——听说主角在工地扛水泥后哭了
- 程渡发现主角被关过——"你以前在哪儿，我不管。但现在——你在这儿。"
