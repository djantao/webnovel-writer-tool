# 第24章 记忆快照

## 本章要点（3句）
1. 陈胖深蹲100公斤×5——三个月的成果，身体突破，从六十公斤蹲不动到一百公斤做五个
2. 三次欲言又止——深蹲后想说咽回去、问完身世激动到嘴边停住、走到门口背对着说"我能不能——"又咽回去，最终大声说"我走了啊江哥！明天见！"
3. 江临渊回忆三百年前第一个徒弟——姓赵，跪了三天三夜，主角因武林盟主身份不能收，"他差点叫我师父。但他没说。我知道他想说。他也知道我知道。但我们都没说破。"
