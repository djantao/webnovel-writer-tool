# 序章 + 前10章章节大纲

叙事视角：第一人称（江临渊）

## 因果链

```
序章A：盟主巅峰——评剑/师弟缝鞋/陆沉"有约"/拒朝廷/女人鞋印
  ↓ 陆沉与顾长风的合作启动
序章B：天牢坠落——铁钉/师弟递馒头/陆沉来访/第二根铁钉/穿越
  ↓ 醒来——一切都不对
第1章：穿越 + 信息之钩（降龙掌无人知）
  ↓ 没钱没身份证没饭吃
第2章：生存挣扎 + 工头收留
  ↓ 扛水泥
第3章：体力证明 + 黄毛拍视频
  ↓ 短视频扩散
第4章："水泥哥"走红 + 老周找上门
  ↓ 进入健身房
第5章：健身房第一天 + 张扬敌意
  ↓ 没证不能教学
第6章：考证困境 + 看到学员动作错误
  ↓ 忍不住指导陈胖
第7章：陈胖来找 + 张扬警告
  ↓ 陈胖成果 + 工友捧场 + 老周决定推他
第8章：双重身份公开 + 老周升实习教练
  ↓ 培训课 + 程渡深入 + 顾长风出现
第9章：考证培训 + 程渡线 + 顾长风认出他
  ↓ 顾长风的邀请需要回应
第10章：第一卷高潮——选择方向 + 告别工地
```

## 各章概要

### 序章A：盟主
- 钩子：信息之钩——什么样的人会从万人跪伏沦落到天牢
- 冲突：江临渊的"不转弯"——拒绝朝廷招揽
- 爽点：无。全章靠"这是一个有原则的人"建立读者认同
- 推法：升级式——女人鞋印暗示暗流涌动
- 场景：练武场(动作)+大殿(对话)+山门(对峙)
- 伏笔：师弟缝鞋(→第2章鞋被偷/补丁)、陆沉"有约"(→第4卷)、女人鞋印(→第4卷)

### 序章B：天牢
- 钩子：不公之钩——铁钉穿骨、师弟被囚、自己人被背叛
- 冲突：在天牢中守住最后一点尊严
- 爽点：无。全章靠"凭什么"驱动
- 推法：断章式——穿越瞬间切断，"我醒来的第一件事，是去摸腰间的剑"
- 场景：天牢(心理+感官)
- 伏笔：陆沉门外来访(脸被抹除→第4卷记忆回来)

### 第1章：醒来（铺垫章）
- 钩子：信息之钩——降龙掌无人知
- 冲突：搞清楚这是哪里——一切都不对
- 爽点：无。全章靠"被时代抛弃"的刺痛驱动
- 推法：反转式——玉佩换不来一个包子
- 场景：心理40% + 过渡30% + 对话30%

### 第2章：空腹（铺垫章）
- 钩子：危险之钩——生存危机
- 冲突：填饱肚子但没有一个铜板
- 爽点：无。暖意——流浪汉的半个馒头
- 推法：升级式——工地招工
- 记忆：饿→师弟的馒头

### 第3章：扛楼（爽点章）
- 钩子：不公之钩——被低估
- 冲突：用体力证明自己
- 爽点：C级——工头多给二十块
- 推法：升级式——黄毛开始拍视频
- 记忆：扛水泥→挑水练功

### 第4章：水泥哥（铺垫章）
- 钩子：信息之钩——"一千个人在看我扛水泥"
- 冲突：不理解"走红"
- 爽点：无
- 推法：升级式——老周在工地门口等他

### 第5章：新入（过渡章）
- 钩子：信息之钩——健身房=这个世界的练功房
- 冲突：从水泥哥到健身房前台
- 爽点：无。暖意——老周给他钥匙
- 推法：反转式——张扬出场质疑

### 第6章：无证（铺垫章）
- 钩子：不公之钩——三百年修为顶不过一章纸
- 冲突：能力无法通过任何渠道证明
- 爽点：无
- 推法：断章式——"这书是反的"

### 第7章：第一次碰（爽点章）
- 钩子：信息之钩——他的知识被换了名字
- 冲突：需要证明的机会
- 爽点：C级——陈胖主动来问"还有没有别的"
- 推法：升级式——张扬警告

### 第8章：第一次证（爽点章）
- 钩子：信息之钩——双重身份被公开
- 冲突：水泥哥+没证教练同时曝光
- 爽点：C→B（双重）——陈胖数据动了+工友集体办卡
- 推法：升级式——老周宣布升实习教练

### 第9章：程渡（铺垫章）
- 钩子：信息之钩——知识可以"翻译"
- 冲突：考证培训 + 程渡深入接触
- 爽点：无。喜剧——"这是药浴？"
- 推法：反转式——顾长风在走廊拦下他

### 第10章：故人（第一卷高潮）
- 钩子：危险之钩——顾长风的邀请
- 冲突：旧世界的招揽 vs 新的方向
- 爽点：B级（情感型）——工友送鞋+笔记本"翻译"+"行。明天。"
- 推法：升级式——新学员出现。"以前是运动员。膝盖废了。"
