# 第二卷：11-15章章节大纲

叙事视角：第一人称（江临渊）

## 因果链

```
第10章：刘雨桐出现 + 告别工地
  ↓ 第一天教刘雨桐
第11章：刘雨桐第一天——站桩教学 + 程渡告知顾长风消息
  ↓ 站桩持续 + 备考
第12章：站桩见效 + 考试通过 + 陈胖老婆加入
  ↓ 正式上班
第13章：正式教练第一天——刘雨桐深蹲 + 初显成效
  ↓ 刘雨桐深蹲进步 + 比赛日
第14章：比赛——拒绝顾长风公开挑战
  ↓ 刘雨桐深蹲达标 + 顾长风暗中打听
第15章：深蹲标准 + 张扬暗箭 + 顾长风约三人火锅
  ↓ 推向第16章：三人火锅正面交锋
```

## 各章概要

### 第11章：刘雨桐
- 钩子：信息之钩——凌晨五点，刘雨桐已经在等（她为什么这么拼？）
- 冲突：克服膝盖恐惧——不是不能站，是不敢
- 爽点：C级——刘雨桐站桩姿势对了（主角技能展现）
- 推法：升级式——程渡告知顾长风比赛邀请
- 场景：训练(50%) + 对话(30%) + 心理(20%)

### 第12章：站桩
- 钩子：信息之钩——"站桩第三天，刘雨桐的腿不抖了"
- 冲突：站桩的内在意义——不是练腿，是练心
- 爽点：C级——考试通过，正式教练
- 推法：升级式——陈胖老婆加入，明天正式上班
- 场景：训练(40%) + 考试(20%) + 火锅对话(20%) + 收尾(20%)

### 第13章：蜕变
- 钩子：信息之钩——正式上班第一天，戴工牌
- 冲突：刘雨桐从站桩到深蹲的跨越
- 爽点：C级——刘雨桐跑了五十米膝盖不疼了
- 推法：升级式——刘雨桐想学"以前练的那种"
- 场景：训练(50%) + 心理(30%) + 过渡(20%)

### 第14章：比赛
- 钩子：信息之钩——顾长风武馆的搏击比赛
- 冲突：现代搏击 vs 真正的武功，顾长风的公开挑战
- 爽点：C级——江临渊当众拒绝顾长风（"不了"）
- 推法：升级式——顾长风约吃饭，江临渊拒绝
- 场景：比赛(40%) + 对话(30%) + 训练(20%) + 收尾(10%)

### 第15章：标准
- 钩子：信息之钩——"刘雨桐的深蹲标准了"
- 冲突：张扬朋友圈暗箭 + 顾长风通过程渡施压
- 爽点：C级——刘雨桐首次感知"气"，眼里的信任从崇拜变成明白
- 推法：断章式——"明天有火锅。有顾长风。有程渡。""有些事——可能一掌也躲不掉。"
- 场景：训练(40%) + 对抗(20%) + 电话(20%) + 收尾(20%)
