# 盟主教你健身 —— 故事结构

## 题材模板

定制五段式（都市古穿今 + 荒诞温暖向）

## 宏观结构

```
序章 (00a-00b)         │ 盟主巅峰 + 背叛入狱 + 天牢穿越
第一卷：坠落 (1-10章)   │ 穿越 + 扛水泥/送快递 + 短视频走红 + 进健身房
第二卷：求存 (11-28章)  │ 当教练 + 考证 + 第一个学员蜕变 + 被叫"师父"
第三卷：破土 (29-50章)  │ 气脉健身法 + 收三徒 + 行业注目 + 不打而胜
第四卷：对决 (51-80章)  │ 旧敌出现 + 商业打压 + 擂台对决 + 身份暴露 + 陆沉真相
第五卷：立派 (81-100章) │ 风暴 + 直播承认 + 传承 + 新"门派"落定
```

## 序章内部节拍

- 00a章：盟主巅峰——评剑/师弟缝鞋/陆沉"有约"伏笔/拒绝朝廷/女人鞋印
- 00b章：天牢坠落——铁钉/师弟递馒头/陆沉来访(脸被抹除)/第二根铁钉/穿越

## 第一卷（现代）内部节拍

- 1-2章：穿越+钩子+活下来
- 3-7章：扛水泥/送快递/搬家/工地——体力活阶段（穿插记忆闪回）
- 8章：短视频走红——"水泥哥"
- 9-10章：健身房老板找上门+告别工地

## 记忆穿插方式

回忆由身体触发——在干体力活的过程中自然闪回。
- 扛水泥 → 挑水练功
- 手上茧破了 → 第一次握剑
- 工地洗澡照镜子 → 师父说"武林盟主不是一天练成的"
- 送快递日行百里 → 轻功训练
