# 角色关系图

## 三个核心三角冲突

### 三角 1：江临渊 ←→ 张扬 ←→ 老周
```
江临渊 — 被看不起 —→ 张扬
张扬 — 暗中找下家 —→ （隐瞒老周）
老周 — 用亡妻关系担保 —→ 江临渊（江不知情）
引爆：第6-8章——张扬举报→老周选择公开挺江
```

### 三角 2：江临渊 ←→ 程渡 ←→ 老周
```
江临渊 — 真的没看出来 —→ 程渡（喜欢他）
程渡 — 暗中介绍客户 —→ 老周（不让江知道）
老周 — 看出来一切 —→ 江临渊（"那人是对你真的好"）
引爆：第三卷拒绝那场戏。没有破裂——一次干净的理解
```

### 三角 3：江临渊 ←→ 顾长风 ←→ 程渡
```
江临渊 — 死敌/招揽/对决 —→ 顾长风
顾长风 — 想通过程渡商业网搞江 —→ 程渡
程渡 — 表面配合/实际摸底 —→ 顾长风（江不知情）
引爆：第四卷第56章——江发现程渡和顾长风吃过饭，第一次对程渡发火
```
